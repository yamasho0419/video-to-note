# ファクトチェック(別エージェント)

添削まで終えた記事を、**書いた経緯を知らない新しいエージェント**に、事実の裏付けだけ確かめてもらう。
書いた本人(このセッションやサブエージェント)は、自分の言い換えのズレに気づきにくい。
発言者の取り違えのような重大な誤りは、この工程で見つかることが多い。

## 依頼のしかた

Agent ツールで新しいエージェントを1つ立てる(subagent_type は general-purpose。fork は経緯を引き継ぐので使わない)。
渡すもの:
- 記事: `{articles}/{番号}_{短縮}.md`
- 字幕: `{transcripts}/{番号}_{短縮}.md`(無ければ `{transcripts}/{video_id}.ja.vtt`)
- テロップ確認用の画像フォルダ: `{images}/{番号}_{短縮}/`(記事に使った画像だけなので、テロップの大半は入っていない)
- 動画: `{videos}/{video_id}.*`(字幕が崩れている箇所は、該当時刻のフレームを切り出してテロップで確かめてよいと伝える。
  試験運用では、これを渡さなかったため、テロップにある語を「字幕に無い」と誤って指摘された)
- 用語集: チャンネルの `glossary.md`

依頼文のひな形(そのまま使ってよい):

```
次の記事が、元動画の字幕に裏付けられているかだけを確かめてください。
文章の読みやすさや構成は評価しないでください(別の工程で済んでいます)。

記事: <path>
字幕: <path>   (自動生成字幕なので誤変換があります。画像フォルダのテロップも根拠に使ってよい)
画像: <dir>
動画: <path>   (字幕が崩れていて判断できない箇所は、ffmpeg -ss <秒> -i <動画> -frames:v 1 で
               フレームを scratchpad に切り出し、テロップを見て確かめてください。「字幕に無い」と
               指摘する前に、その時刻のテロップを確かめること)
用語集: <path>

特に次を探してください。
F1 その場の1回の質問や1人の発言を「よく」「多い」「〜をいただくことがあります」と一般化していないか
F2 「〜と思う」を断定に、断定を推量に、「可能性がある」を「高い」に、意図を完了に変えていないか
F3 字幕に無い語(性別・家族構成・年齢・徒歩・副詞・感情語・同意の言葉・概算の実績)を補っていないか
   (冒頭の定型の自己紹介と、末尾のフッターは固定文なので対象外)
F4 聞き手・ゲスト・話者の発言を取り違えていないか(エピソード・意見ごとに話者を確かめる)
F5 条件や但し書きを落として意味が変わっていないか
F6 「別の記事」と書いた箇所(参照先が実在するかは呼び出し側が確かめる)
F7 別々の発言を1つの鉤括弧にまとめていないか
F8 誤変換をそのまま写していないか/誤変換の補正が妥当か
F9 記事の中で数字が食い違っていないか

指摘ごとに次の形で返してください。
| 重大度(高/中/低) | 記事の引用 | 字幕の該当箇所(時刻つき) | 問題 | 直し方(削る/元の表現に戻す) |
裏付けが取れた数字・固有名詞は最後に一覧にしてください。
```

## 返ってきた指摘の扱い

- 字幕かテロップで食い違いを確かめられたものだけ直す。エージェントの読み違いの可能性があれば直さず、理由を記録する
- 直す方向は **削る・元の発言に戻す** だけ。新しい情報を足して埋め合わせない
- テロップと字幕のどちらが正しいか迷ったら、該当時刻のフレームを切り出して目で見る(`extract_shots.sh` を scratchpad に向けて使う)
- 「高」が出て、削るか元に戻すかで解消できないときは `human_review` に入れる
- 指摘と対応は `critiques/{video_id}.md` の「別エージェントによるファクトチェック」に表で残す(`critique.md` の書式)
- 直したあとは lint をもう一度通す
